# DesignPattern 准确度复核

复核日期：2026-10-27。基线：e31ee7ee6f79f33339fdaac88bf999a158fe4385；原有 40 种，新增实干家后 41 种。

## 结论

项目可作为风格启发与 token 交换画廊；不能认定为 40 套官方设计系统或艺术流派的准确复刻。数据链可自动验证，布局/材质/原生交互需要独立视觉验收。没有为“整个项目准确度”编造一个百分比。

## 已修复

- 次按钮错误复用正文色：瑞士国际主义、构成主义原对比 1:1，IBM Carbon 约 1.57:1；现在使用独立 on-secondary 语义。
- DTCG 原导出以 CSS 字符串表示颜色、尺寸、时长、字体列表及阴影字段；改为 2025.10 值结构，保留原始 CSS 扩展。em 按种子 baseSize 转 px，仅作为交换近似，响应式相对关系仍以 CSS 为准。
- 不支持的阴影不再静默变为透明；所有现有阴影均经过解析检查。
- 渐变和纹理由共享函数供预览与 CSS 导出使用；消费方需添加 style-scope 类。
- Material 3 的示例控件由 44px 改 48px；Carbon 紧凑控件由 40px 改 32px。
- Geist 导出增加字体回退；实际字体仍需加载。
- 详情页键盘左右键不再抢占 tab/button 等控件；移动预览内容允许滚动；默认预览优先声明支持的平台。
- 对比文案纠正：低于 3:1 不能靠放大文字解决；aria-disabled 不等于禁止操作；新增 reduced-motion 样式。
- Catppuccin 的 Mauve/Lavender 命名纠正。

## 仍未解决或未验证

- 多数风格共用 hero、按钮、三张卡片和列表模板；艺术流派、Bento、杂志/报纸等结构未完整呈现，已在详情页和导出文档明确范围。
- 主色和弱文字的既有低对比组合保留并列入下表，没有为通过检查擅改官方色板。需在后续增加可读文字角色或可访问变体。
- 宿主深色切换不生成每个种子的深色变体；玻璃/渐变实际像素对比需浏览器测量。surfaceOpacity 当前是元数据，表面 alpha 由颜色值承担。
- 公共 Google Fonts、next/font 构建下载和各字重可用性受网络影响；中文不必然呈现所选拉丁字体的风格。
- 未进行浏览器截图、交互/E2E、ZIP 下载实测；未完成全量 npm ci、TypeScript 类型检查、ESLint 或 Next build。依赖缓存不完整且 shell 网络不可达。
- 已执行不依赖第三方包的 Node 24 token/export 回归测试；TS/TSX 全文件仅经 esbuild 语法转换，不等于类型检查。

## 附件接入边界

附件为用户提供的 tokens.json（实干家 B 端初稿，2026-10-27）。存入 src/lib/styles/sources/shigan.tokens.json，原描述、别名和值保持不变；ZIP 增加 design/source-tokens.json，DTCG 扩展 sourceTokens 也保留完整源数据。源文件自身是旧式颜色值，保留原件不等于声称其符合新 DTCG 颜色结构。

适配从原文件解析：黄 #FFCC00、黑字、深色导航 #393847、浅灰页面、4px 按钮圆角、2px 标签圆角、8px 卡片圆角、32px 桌面按钮、44px 表格行。移动端另外加大触控目标；字体是截图推断。未选中 tab 图标原 #888891 仅适合图形，文字采用 #B0AFB8。风险色、在线/离线、链接、图表色使用独立语义。

未声称“实测”得到独立验证：原始截图未在本任务提供；阴影 none、动效、字重和附件外字号属于适配补全。

## 可重现检查

需要 Node >=24（registerHooks/stripTypeScriptTypes）。运行 npm test；运行 npm run audit 重建本报告。联网环境另运行 npm ci、npx tsc --noEmit、npm run lint、npm run build，并用桌面与移动宽度检查 41 个详情页和导出套件。
